# dll_baseline.txt - imports the bundle may leave to the PC (APP_SPEC r1 8 h, amended by r2 R2.4.7 and R2.6 8 h).
# Read by packaging\tests\dll_check.py (Task H). One line per DLL:   name | kind | reason
#   name : a DLL file name, case-insensitive; "*" matches any characters (api sets)
#   kind : system        - every Windows 10 x64 (1809, build 17763, or newer) and 11 has it in System32
#          driver        - comes with the NVIDIA graphics driver; loaded at run time; never bundled
#          bundle-only   - must be satisfied by the bundle (version-checked), NEVER by this baseline
#          delay-only    - never called by the checker; may be missing only as a DELAY-loaded import
# Every import of every .dll / .pyd in the dist must be in the bundle or on a "system" / "driver" line.
# Delay-loaded imports are listed by dll_check separately; DirectML.dll is NOT on this list any more: onnxruntime is
# not in the GPU build at all (R2.4.2), so any reference to it is a finding.
